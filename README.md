- **第一编 卷零·哲学总纲**（原文全录）：道（三易，第一表达式 0+1=1）· 至衡 · 中态 · 阴阳 · 五道 · 存在度 · 中庸 · 纠错
- **第二编 零卷新章**：阴阳四层与存在度递减合论——「递减是道上的势，不是现实里的线」＋ **0+1=1 推导阴阳四层**（项间读出源层、运算符读出交换层、累积读出势层、等号读出关系层）
